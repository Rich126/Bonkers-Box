# Spencer Games v4.1 — Speedway Slide

## New Local Mode game
- Adds **Speedway Slide** as a completely separate game from Draw Dash.
- 2–6 riders take turns on the same device.
- Every rider gets one fixed three-lap solo time trial.
- The bike accelerates automatically; the only live controls are **LEFT** and **RIGHT**.
- Speedway handling includes momentum, steering lean and rear-wheel slide so RIGHT can be used to catch/correct an over-rotation.
- Running onto the grass or too close to the safety fence scrubs speed and records an off-line moment.
- Adds shale dust, stadium/crowd visuals, start tapes, lap/time/speed HUD and a lightweight synthesized engine note.
- Records all three lap times, best lap, total time and off-line moments.
- Final leaderboard ranks all riders by fastest three-lap total.
- Keyboard arrow controls are supported for desktop testing.

## Integration
- Adds a Speedway Slide card to the Local Mode game menu.
