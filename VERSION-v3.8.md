# Spencer Games v3.8

## Impressions
- Adds impression rounds to Creative Party and Spencer Mix.
- Includes celebrity impressions and dynamic player impressions using names from the current room.
- Player targets are stored in the shared game state so host and players always see the same prompt, including after reconnects.
- Player targets rotate before reuse where possible.
- Impression rounds use microphone recording, allow up to 15 seconds, and flow through the existing anonymous voting/heats/final system.
- No celebrity photos, music clips or external copyrighted media are bundled.
