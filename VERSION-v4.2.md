# Spencer Games v4.2 — Speedway Touch Steering Fix

## Speedway Slide
- Steering buttons now capture a press until the finger is lifted.
- Removed pointer-leave steering cancellation, so sliding slightly outside the button no longer stops steering.
- Added iOS-safe touch handlers and pointer capture.
- Disabled text selection, long-press callouts and drag behaviour during Speedway racing.
- LEFT / RIGHT controls now work as proper press-and-hold game controls.
