# Spencer Games v4.4 — Question Bank 2.0

## Spencer Live
- Replaces broad Junior / Standard quiz selection with exact numeric ages from 5 to 100.
- Adds 720 individually age-rated questions across eight topics.
- Each question stores an overlapping minimum, target and maximum age so nearby ages receive a natural mixture rather than a rigid school-style band.
- Adds 210 genuinely simple questions written specifically for ages 5–6.
- Adds broader Science, Geography and Animals coverage to reduce chemical-symbol, capital-city and baby-animal repetition, including dedicated medium-age Science and Geography sets.
- Keeps each round on the same topic while resolving a different age-appropriate fact on each player's phone.
- The host can preview the actual questions being shown to the different ages currently in the room.
- Existing players stored with the old Standard / 5–7 / 8–11 / 12–15 / 16+ values remain compatible.
