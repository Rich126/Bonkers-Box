# Spencer Games v4.8 — Unified Speedway corporate theme

## Whole experience

- Extended the Speedway Slide corporate motorsport look across the Spencer Games home, every Local game shell and Spencer Live.

- Rebuilt the Local game menu cards as a single cohesive Spencer Games catalogue while preserving every game and its descriptions.

## Standalone games

- Added matching Spencer Motorsport branding to Draw Dash.
- Added matching Spencer Performance Lab branding to Flash Frenzy.
- Kept Speedway Slide on its existing v4.7 design and connected it to the shared theme.

## Spencer Live

- Added the official Spencer Games crest and a Spencer Games Network header.
- Restyled hosting, joining, settings, status, question and leaderboard surfaces to match the Local experience.

Functional correct/wrong states, player colours, reaction targets and drawing colours are intentionally retained for usability. Gameplay, Speedway handling, fastest-lap records, question logic and multiplayer schemas are unchanged. No Supabase changes are required.
